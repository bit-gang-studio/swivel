# Anti-Roadmap

Things we decided not to build, and what would make us revisit.

| Not building | Why | Revisit when |
|---|---|---|
| Web app version | Local dev tool: needs localhost access and should be free to run | A paid cloud tier is being planned |
| Email client rendering (Outlook, Gmail, Apple Mail) | Separate product idea; Swivel is for browsers | Users ask for it repeatedly |
| Real iPhone Safari, Windows Edge, Android devices | Needs Mac, Windows or emulator machines; that's the paid cloud tier | Free app has steady users |
| Share links, PR checks, snapshot history | Paid cloud features | Free app has steady users |
| A domain and website | GitHub is enough for now | Before the first public release is promoted |
| Full Chrome DevTools replacement | Keep dev tools simple and focused on cross-engine differences | Users say the simple tools block them |
